# 取文与阅读策略

目标是用最少的阅读量拿到足够的证据。读得全不等于读得懂；先把论文的结构和证据定位清楚，再决定哪些页值得逐行读。

## 先确认来源

用一句话告诉用户你实际读的是什么，例如：

> 读的是 arXiv v3 的 PDF（18 页），不是 NeurIPS 正式版。

用户能据此判断版本差异、页码是否对得上。来源不确定时（比如只拿到摘要页）也要说出来，后面的笔记会以此为证据边界。

| 输入 | 首选做法 | 备选 |
|---|---|---|
| 本地 PDF | 用 Read 直接读，按 `pages` 分批 | 扫描件同样用 Read（按图像识别） |
| arXiv 链接 / ID | `curl` 下载 PDF 后 Read | `arxiv.org/abs/...` 页面取摘要，`arxiv.org/html/...` 或 `ar5iv` 取 HTML |
| DOI | `curl -L https://doi.org/<doi>` 尝试拿全文 | 查 arXiv / 作者主页 / 开放获取版本；都没有就只基于摘要 |
| 论文网页 | WebFetch 取正文 | `curl` 下载后用简单脚本去标签 |
| 粘贴文本 | 直接用，先判断是摘要、节选还是全文 | 只有摘要时明确标注"证据有限" |

## 本地 PDF

```text
Read(file_path="/path/to/paper.pdf", pages="1-10")
Read(file_path="/path/to/paper.pdf", pages="11-20")
```

- 每次不超过 10–20 页；页数多时先读 1–10 页判断结构，再定向读方法和实验。
- 图和表所在的页至少亲眼看一遍。正文里的"显著提升"没有意义，表格里的数字才是证据；图能告诉你趋势和失败案例。
- 公式密集的页如果看不清上下标，去正文或附录找同一公式的文字描述，不要靠猜。
- 扫描件：Read 会把页面渲染成图像来读，通常可行；手写批注、低分辨率公式容易出错，关键数字必须和表格/正文交叉核对。

## arXiv

```bash
curl -L --fail -o /tmp/arxiv-1706.03762.pdf "https://arxiv.org/pdf/1706.03762"
```

- 下载失败（403/404）时，先用 WebFetch 打开发布页确认版本，再试 `https://arxiv.org/pdf/1706.03762v7` 这类带版本号的地址。
- 拿不到 PDF 时，`https://arxiv.org/html/<id>`（较新论文）或 `https://ar5iv.labs.arxiv.org/html/<id>` 通常有完整 HTML，公式和表格可用。
- 记录版本号。预印本和正式版在实验数字上可能不同，笔记里写清楚读的是哪一版。

## DOI 与付费墙

```bash
curl -L -A "Mozilla/5.0" -o /tmp/doi-landing.html "https://doi.org/10.xxxx/xxxxx"
```

- 返回 HTML 落地页时，WebFetch 取摘要、作者、发表信息；全文通常在出版社的 PDF 链接后面，可能需要订阅。
- 依序尝试：arXiv 同名预印本 → 作者主页 / 实验室页面 → OpenReview / 会议 proceedings → 开放获取机构库。
- 全都拿不到全文时，直接告诉用户"只能拿到摘要，方法和实验读不到"，并给两个选项：基于摘要出速读卡片（标注证据有限），或请用户提供 PDF。**不要根据标题、摘要和领域常识补全方法细节**——那种笔记看起来完整，实际不可信。

## 网页 HTML

- WebFetch 返回的内容可能被截断。先确认有没有拿到方法、实验、结论三部分；缺了哪部分就针对性地再取一次。
- 需要整页原文时，`curl -L -o /tmp/paper.html <url>`，再用 Python 的 `html.parser` 去标签（不要依赖未安装的 pandoc / pdftotext）。
- 注意网页版经常缺图表。若关键结论只靠图，回到 PDF 或原文图床确认。

## 粘贴文本

- 先判断文本覆盖到哪：只有摘要、只有方法、还是全文。这决定了笔记里哪些部分必须标"未验证"。
- 用户粘贴的可能是笔记、翻译或二手总结，不一定是原文。引用时以"用户提供的文本"为准，不要假装是原文。
- 文本里出现 `[1]`、`Figure 3` 之类引用但对应内容缺失时，指出来，不要自行补全。

## 读多少：取舍策略

| 论文长度 | 建议 |
|---|---|
| ≤12 页（会议短文） | 全读 |
| 13–25 页 | 摘要、引言、方法、实验、结论全读；相关工作略读；附录按需 |
| >25 页（期刊长文 / 综述） | 先读摘要、引言末尾的贡献列表、方法总览图、实验主表、结论；其余按问题定位 |
| 综述 | 读分类框架图和结论，不要逐篇读引用文献；需要具体方法时再去读原始论文 |

附录的用法：当笔记里某个数字、消融或实现细节需要确认时才读，不要把附录当成"更完整所以就一起读"的部分。

## 读的时候顺手记下

- 章节/图表/页码位置（写进笔记的"原文定位"）
- 作者的关键假设，以及它在什么条件下会失效
- 论文里没有解释、但影响结论的地方（baseline 选择、数据清洗、超参搜索预算）
- 让你意外的结果，包括负面结果

这些是后面写"局限与可疑点"和"与我相关"的原材料，事后再回去找通常要重读一遍。
